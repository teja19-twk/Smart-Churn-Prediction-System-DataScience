# Exploratory Data Analysis (EDA)

The Exploratory Data Analysis (EDA) phase was performed to understand customer behavior, identify churn trends, discover hidden patterns, and generate business insights from the telecom customer dataset. EDA plays a critical role in transforming raw data into meaningful information for decision-making and predictive modeling.

## Churn Pattern Analysis

Customer churn behavior was analyzed using multiple demographic and service-related features such as contract type, tenure, monthly charges, internet services, payment methods, and customer support services. The analysis revealed important churn trends and customer retention patterns.

Key observations included:

* Customers with month-to-month contracts showed higher churn rates.
* Customers with higher monthly charges were more likely to churn.
* Long-tenure customers demonstrated better retention behavior.
* Lack of services such as online security and tech support increased churn probability.

## Data Visualizations

Various visualizations were created using Matplotlib and Seaborn to better understand the dataset and customer behavior patterns. Visual analysis included:

* Count plots
* Histograms
* Box plots
* Pie charts
* Correlation heatmaps
* Distribution plots

These visualizations helped identify customer segmentation, revenue patterns, churn distribution, and service usage behavior.

## Correlation Analysis

Correlation analysis was performed on numerical features such as Monthly Charges, Total Charges, Tenure Months, Churn Score, and CLTV. Heatmaps were generated to identify relationships between variables and understand feature importance for machine learning modeling.

## Business Insights

EDA generated several valuable business insights that can support customer retention strategies:

* Customers using short-term contracts are more likely to leave.
* Customers without technical support services have higher churn risk.
* Higher customer lifetime value (CLTV) is associated with longer retention.
* Customer engagement and bundled services improve loyalty and reduce churn.

## Technologies Used

* Python
* Pandas
* Matplotlib
* Seaborn
* Google Colab

The insights obtained during EDA were later used for KPI analysis, dashboard creation in Power BI, and machine learning-based churn prediction.
